# Видео на тему: $ARGUMENTS

Ты делаешь законченное видео под ключ. Работай сам, вопросы — только в шаге 0.

## 0. Короткий бриф (один вопрос AskUserQuestion, максимум 3 пункта)
Спроси только то, чего нет в аргументах:
- **Длительность**: 30 сек (Reels/Shorts) · 1–2 мин · 5–6 мин (конкурс/доклад)
- **Формат**: 16:9 1920×1080 (YouTube/конкурс) или 9:16 1080×1920 (Reels/TikTok/Shorts)
- **Голос**: я озвучу сам (дай текст) · без голоса, только кинетические титры + музыка
Стиль по умолчанию: тёмный кинематографичный, плёночное зерно, виньетка, letterbox.

## 1. Папка проекта
`~/Projects/videos/<короткий-slug-темы>/` со структурой:
```
composition/index.html   composition/audio/   composition/img/   composition/renders/
sources/                 deliverables/
```

## 2. Факты (обязательно)
- WebSearch по теме, 5–10 надёжных источников. Каждую цифру и дату сверь минимум по 2 источникам.
- Сохрани `sources/Сверка_фактов.md` (факт → статус → ссылка) и `deliverables/Список_источников.md`.
- Ничего не выдумывать. Сомнительное — не вставлять или пометить пользователю.

## 3. Сценарий
- Раздели на сцены по 15–40 сек: хук в первые 3 сек → развитие → кульминация → финал/вывод.
- `deliverables/Сценарий.md`: таблица «сцена · время · что на экране · текст за кадром».
- Если голос пользователя — `deliverables/Текст_для_озвучки.md`: по файлу на сцену
  (scene01.m4a, scene02.m4a…), ударения и паузы помечены, цифры прописью.
  Затем **остановись и жди записи**. Пока ждёшь — уже собирай графику под примерные тайминги.

## 4. Композиция (загрузи скилл hyperframes перед написанием)
- Корневой `data-duration` = общая длина; сцены — `<section data-start data-duration>`.
- Один paused GSAP timeline `window.__timelines["main"]`, всё seek-safe:
  у повторных `fromTo` на одном элементе — `immediateRender:false`; текст менять через tween `onUpdate`, не `tl.call`.
- Максимум движения: Ken Burns на фонах, wipe через clipPath, счётчики цифр, kinetic typography
  по словам, CSS 3D (perspective + preserve-3d, rotationX/Y, z) для карт/карточек/календарей,
  частицы, световые свипы, переходы между сценами внахлёст 0.5–0.8 сек.
- Плёнка: зерно (mix-blend overlay), виньетка, лёгкий flicker, letterbox.
- Картинки: только реальные (Wikimedia Commons PD/CC с указанием автора, фото пользователя)
  или явно графические/сгенерированные с подписью «реконструкция». **Никогда не выдавать
  сгенерированное за архивное фото.**
- Аудио: `<audio data-audio-group="voiceover">` для голоса; музыка `data-volume="0.15–0.25"`.
  Голос нормализовать: `ffmpeg -af loudnorm=I=-16:TP=-1.5:LRA=11`.
  Тайминги сцен подогнать под реальную длину записей (ffprobe).

## 5. Проверка
- `npx hyperframes check` — 0 ошибок.
- `npx hyperframes snapshot --timeout 20000` на ключевых секундах каждой сцены — посмотри кадры
  сам (Read png), исправь налезания, обрезки, пустые кадры.

## 6. Рендер и выдача
- Мастер: `npx hyperframes render` → `renders/FINAL.mp4`, затем
  `ffmpeg -c:v libx264 -crf 20 -preset slow -c:a aac -b:a 192k` → `renders/<Название>_1080p.mp4`.
- Превью <30 МБ (crf 27–28, 720p) → отправить пользователю через SendUserFile.
- Большой файл — показать через reveal_path.
- В конце коротко: что получилось, длительность, где файлы, что можно улучшить (свои съёмки, хроника).
